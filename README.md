# 🧱 Arquitetura

Gosto de pensar em software como uma cidade.

O código são os edifícios.

As APIs são as avenidas.

Os bancos de dados são os arquivos e bibliotecas.

Os servidores são a infraestrutura.

E a arquitetura é aquilo que faz tudo funcionar em conjunto.

Por isso, estudo e aplico conceitos como:

```text
                    ┌─────────────────────┐
                    │     FRONT-END       │
                    │ JSP • JSF • Struts  │
                    └──────────┬──────────┘
                               │
                               ▼
                    ┌─────────────────────┐
                    │      WEB / API      │
                    │ Servlet • REST/SOAP │
                    └──────────┬──────────┘
                               │
                               ▼
                    ┌─────────────────────┐
                    │      BACK-END       │
                    │ Java • Spring • EE  │
                    └──────────┬──────────┘
                               │
                               ▼
                    ┌─────────────────────┐
                    │    PERSISTÊNCIA     │
                    │ JPA • Hibernate     │
                    └──────────┬──────────┘
                               │
                               ▼
                    ┌─────────────────────┐
                    │      DATABASE       │

                    └─────────────────────┘
```
