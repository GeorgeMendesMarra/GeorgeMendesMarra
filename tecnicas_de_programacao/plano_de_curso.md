# Plano de Curso — Técnicas de Programação

**Curso:** Engenharia de Software
**Carga horária:** 80h (a ajustar conforme grade)
**Linguagem de referência:** Java

## Objetivo Geral

Capacitar o aluno a projetar e implementar soluções orientadas a objetos, aplicando encapsulamento, herança, polimorfismo, abstração e tratamento de exceções em aplicações Java.

## Objetivos Específicos

- Compreender os conceitos fundamentais de objetos, classes, atributos, métodos e mensagens
- Aplicar encapsulamento e boas práticas de modelagem de classes
- Implementar hierarquias de classes usando herança e polimorfismo
- Utilizar classes abstratas e interfaces para generalização e definição de contratos
- Tratar exceções de forma robusta, incluindo exceções personalizadas
- Desenvolver uma aplicação orientada a objetos completa, integrando todos os conceitos

---

## N1 — Fundamentos de Objetos e Encapsulamento

**Peso/avaliação:** prova teórica + exercícios práticos de modelagem de classes

### Conteúdo programático

| Semana | Tema | Atividade |
|---|---|---|
| 1 | Revisão de lógica e introdução a objetos: o que são objetos, atributos e operações | Aula expositiva + exercícios |
| 2 | Classes e objetos: sintaxe Java, construtores, instanciação | Exercícios práticos |
| 3 | Encapsulamento: modificadores de acesso, getters/setters | Exercícios práticos |
| 4 | Mensagens entre objetos: métodos, parâmetros, retorno, sobrecarga (overload) | Exercícios práticos |
| 5 | Tipos primitivos x tipos referência; atributos estáticos e de instância | Exercícios práticos |
| 6 | Modelagem de classes para um domínio simples (ex.: cadastro de produtos/clientes) | Estudo de caso |
| 7 | Revisão geral | Lista de exercícios revisão |
| 8 | **Avaliação N1** | Prova + entrega do exercício de modelagem |

### Entrega N1

Pequeno sistema (console) com 2–3 classes relacionadas por composição/associação simples, aplicando encapsulamento e construtores corretamente (ex.: sistema de cadastro de alunos e disciplinas).

## N2 — Herança, Polimorfismo, Abstração e Exceções

**Peso/avaliação:** projeto prático + prova teórica

### Conteúdo programático

| Semana | Tema | Atividade |
|---|---|---|
| 9 | Herança: superclasses e subclasses, `extends`, `super` | Aula expositiva + exercícios |
| 10 | Polimorfismo: sobrescrita (override) e ligação dinâmica | Exercícios práticos |
| 11 | Classes abstratas e o operador `instanceof` | Exercícios práticos |
| 12 | Interfaces: definição de contratos, múltipla implementação | Exercícios práticos |
| 13 | Tratamento de exceções: hierarquia, `try/catch/finally`, `throws` | Exercícios práticos |
| 14 | Exceções personalizadas (checked/unchecked) | Exercícios práticos |
| 15 | Orientação e desenvolvimento do projeto final | Trabalho supervisionado |
| 16 | Apresentação/entrega do projeto + **Avaliação N2** | Prova + entrega do projeto |

### Entrega N2

Projeto prático orientado a objetos com:
- Hierarquia de pelo menos 3 classes (herança + polimorfismo)
- Ao menos uma interface ou classe abstrata
- Tratamento de exceções, incluindo pelo menos uma exceção personalizada
- Sugestões de tema: sistema de folha de pagamento (Funcionario -> Gerente/Vendedor), sistema de biblioteca, loja com diferentes tipos de produtos/pagamento

---

## Metodologia

Aulas expositivas dialogadas intercaladas com laboratório de programação (mão na massa), estudos de caso e desenvolvimento incremental do projeto final ao longo do N2.

## Critérios de Avaliação

- N1: prova teórico-prática (peso maior) + exercício de modelagem de classes
- N2: prova teórica + projeto prático (peso maior)
- Média final: conforme critério institucional (N1 + N2) / 2, respeitando o regimento da UniAlfa
