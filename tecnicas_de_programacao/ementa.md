## O que o aluno precisa fazer

Com base nessa ementa, a disciplina de Técnicas de Programação foca em consolidar os fundamentos da programação orientada a objetos (POO), normalmente usando Java como linguagem de referência. De forma geral, o aluno precisa:

### 1. Dominar os conceitos fundamentais de objetos

- Entender o que são objetos, atributos (estados) e operações (comportamentos)
- Compreender troca de mensagens entre objetos e a diferença entre método e mensagem
- Diferenciar classe de objeto (instância) e entender o papel do construtor na instanciação

### 2. Trabalhar com tipos, classes e encapsulamento

- Usar tipos primitivos e tipos referência (classes) corretamente
- Aplicar modificadores de acesso (public, private, protected) e encapsulamento
- Projetar classes coesas, com atributos privados e métodos de acesso (getters/setters)

### 3. Aplicar os pilares avançados da POO

- Herança: criar subclasses a partir de superclasses, reaproveitando e especializando comportamento
- Polimorfismo: sobrescrita (override) e sobrecarga (overload) de métodos, ligação dinâmica
- Abstração e generalização: uso de classes abstratas e interfaces para definir contratos comuns

### 4. Tratar exceções de forma adequada

- Diferenciar erros de exceções e conhecer a hierarquia de exceções em Java (checked/unchecked)
- Usar try/catch/finally e a cláusula throws
- Criar exceções personalizadas para regras de negócio específicas

### 5. Integrar os conceitos em aplicações práticas

- Modelar pequenos sistemas orientados a objetos (ex.: cadastro, sistema de biblioteca, folha de pagamento)
- Aplicar herança e polimorfismo em hierarquias de classes reais (ex.: Funcionario -> Gerente, Vendedor)
- Tratar exceções em cenários de entrada de dados e regras de negócio

### Entregas típicas em disciplinas com essa ementa

- Exercícios progressivos de modelagem de classes (do simples ao com herança/polimorfismo)
- Projeto prático de um pequeno sistema orientado a objetos com tratamento de exceções
- Prova ou trabalho teórico-prático sobre os quatro pilares da POO
- Estudo de caso comparando solução procedural x solução orientada a objetos para o mesmo problema
