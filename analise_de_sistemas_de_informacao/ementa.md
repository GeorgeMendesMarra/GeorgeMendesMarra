# Ementa

Evolução de metodologias de desenvolvimento de sistemas. Métodos de análise e projeto de
software. Levantamento de requisitos. Análise orientada a objetos. Diagramas da Linguagem
de Modelagem Unificada (UML): caso de uso, classe, objetos e sequência. Uso de ferramentas
CASE para modelagem com UML. Processo unificado. Estudos de caso utilizando UML.
